視差滾動效果

作者：Vineet Kumar

什麼是視差滾動？

視差滾動是一種網頁設計技巧，讓網站背景以比前景更慢的速度移動。當訪客向下捲動時， 會產生 3D 效果，增添景深並創造更沉浸的瀏覽體驗。視差來自視覺錯覺。 由於人眼會將近處物體看得比遠處物體更大，我們會感覺遠處的物體移動得更慢。 這種錯覺長久以來被應用於不同媒介的視差效果中，以營造更真實的感受。 它最早被用於傳統動畫，如迪士尼的《白雪公主與七個小矮人》，也出現在《超級瑪利歐》等電玩遊戲中。 隨著 CSS 與 HTML 的發展，視差效果也逐漸演進到今日的網頁設計領域。

2007 年，網頁開發者 Glutnix 在部落格分享了瀏覽器中視差滾動的早期實作之一， 包含使用 JavaScript 與 CSS 2 的範例程式與示範，支援 Internet Explorer 6 等當時的瀏覽器。 然而直到 2011 年 HTML5 與 CSS3 出現後，這項技術才在網頁設計師之間廣為流行。 擁護者認為它是擁抱 Web 流動性的一種簡單方式，並以視差背景作為提升使用者參與感與整體體驗的工具。 不過，普渡大學在 2013 年發布的研究指出：「……雖然視差滾動強化了使用者體驗的某些面向， 但未必能改善整體使用者體驗。」


為什麼要使用視差圖像？

    設計師應該嘗試視差圖像的主要原因有兩點：

  • 有助於講故事

    視差圖像非常適合敘事。好的設計重視溝通——當我們設計網站時，希望與訪客互動， 並講述關於產品、服務或品牌的精彩故事。視差滾動能讓訪客沉浸在獨特的線上體驗中， 甚至可以打造單頁式網站，讓訪客不必切換頁面就能讀完整個故事。

  • 有助於提升使用者參與度

    視差圖像可以提升使用者參與度。降低網站跳出率是網頁設計中需要關注的目標之一。 跳出率衡量的是僅瀏覽一頁就按下「返回」或關閉分頁的訪客比例。高跳出率會影響搜尋排名， 因此任何降低跳出率的措施都值得投入。精心打造的視差頁面能提供動態體驗， 往往能讓使用者停留更久。


如果你想在網站加入視差滾動效果，建議考慮以下技巧。

  • 選擇性使用

    視差滾動在特定元素上使用時更有力，而不是所有頁面、隨時使用。 可以用在標題或首頁等區域。你希望視差滾動能強化網站設計，而不是分散使用者注意力。

  • 圖片壓縮

    視差滾動會使用多種媒體檔案與 CSS 圖形來營造景深。 不要因為過大的圖片檔案導致載入過慢而影響網站效能與使用體驗。

  • 玩轉色彩

    視差滾動不只是前景與背景圖片，也包含色彩的運用。 你可以在背景使用較低飽和度的色調，在前景使用更鮮活的色彩，以創造更強烈的景深感。
